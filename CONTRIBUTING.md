# Contributing to GeekTV

Thank you for helping improve GeekTV.

1. Open an issue describing the board/chip, firmware version, reproduction
   steps, expected result, and actual result.
2. Fork the repository and create a focused branch.
3. Build the affected PlatformIO environment and run available Node tests.
4. Keep ESP8266 RAM, flash, blocking time, and OTA partition limits in mind.
5. Update the relevant documentation when a setting, endpoint, screen, or
   installation step changes.
6. Submit a pull request with a concise summary and test evidence.

Before committing, search for secrets and personal data. Never include Wi-Fi
credentials, access tokens, webhook secrets, configuration exports, private
repository names, personal photos, device IP addresses, or absolute local
paths. Use fictional examples such as `octo-user/demo-dashboard`,
`acme-labs/api-service`, `ExampleWiFi`, and `192.168.1.50`.

By submitting a contribution, you agree that it may be distributed under the
repository's MIT License.
