The GeekMagic SmallTV is a small cube with a 1.54" colour screen, an ESP inside,
and a USB-C port. GeekTV 0.8.3 provides two clocks, a three-day forecast,
JPEG/GIF gallery, Codex usage, GitHub GH//STAT and a stock ticker. Every screen
is selected in the built-in web UI or added to Carousel, and firmware updates
over Wi-Fi.

:::caution[Confirm the hardware variant]
The browser emulator cannot verify the exact panel revision, backlight
polarity, SPI behaviour, partition layout, or browser-vs-bitmap font
rasterization. Keep a recovery image and use only the build for your chip.
:::
